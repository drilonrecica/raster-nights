# Raster Nights 0.1.0-rc.1

This is a local release candidate for Raster Nights 0.1. It is intended for
final native, browser, packaging, and accessibility verification. It is not the
final public release.

## Included

- The native `raster-nights` terminal application and static browser build.
- The DRX-90 boot, AfterHours catalog, manuals, settings, and local persistence.
- Signal Stack and Loopback, plus the discoverable Packet Sweep program.
- Deterministic release archives for Linux x86-64, macOS Intel, macOS Apple
  Silicon, and the browser.
- SHA-256 checksums and a generated Homebrew formula.

## Privacy

The native application does not make outbound requests. The browser loads the
bundled same-origin site and application files, then initiates no gameplay,
telemetry, score, diagnostic, update, or remote-content requests. Records and
settings stay on the local device.

## Candidate limitations

- macOS Intel and Apple Silicon runtime behavior still requires verification on
  physical or virtual macOS systems.
- Archives are not signed or notarized.
- This candidate does not publish a GitHub release, deploy the website, or
  update a Homebrew tap automatically.

The final `v0.1.0` release requires explicit owner acceptance after the
remaining platform checks pass.
