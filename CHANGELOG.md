# Changelog

All notable public changes to Raster Nights are recorded here. Versions follow
[Semantic Versioning](https://semver.org/).

## [Unreleased]

- Development continues toward the first public release.

## [0.1.0-rc.1] - Unreleased

### Added

- Native terminal and browser hosts for the DRX-90 system experience.
- Deterministic Signal Stack, Loopback, and hidden Packet Sweep game sessions.
- Local-only settings, records, discovery state, and diagnostics.
- Keyboard, mouse, and browser touch input through shared semantic actions.
- Bundled catalog, manuals, archive material, and static project website.
- Deterministic native and browser archives, checksums, and Homebrew formula
  generation.

### Security and privacy

- The native application makes no outbound network requests.
- After its bundled static files load, the browser application performs no
  telemetry, score, diagnostic, update, or remote-content requests.
